# 需求基线

## 0. 最终产品形态

独立桌面浏览器 App 是最终交付，包含原生窗口/标签/地址栏/设置/下载/更新、内嵌 agent 运行时、自有 Profile、密码本、原生挑战接管与审计。当前 stock Chrome 仅承载执行引擎验证。既有密码和登录态通过原生导入向导处理，秘密不进入模型或普通审计。详见 docs/desktop-app.md。

## 1. 产品目标

浏览器承担 AI 与网页之间的执行、恢复、安全和证据留存职责。模型侧只保留任务规划与语义决策，避免重复生成低层轨迹、等待、剪贴板、挑战重试等细节。机器无法可靠完成时才占用人工时间。

## 3. P1：替代 neo 的日常工作流

1. **页面理解**：完整 AX 树、跨 iframe 引用、元素后端节点 ID、可见性/遮盖判断、截图区域定位。
2. **neo `run` 兼容**：隔离 JavaScript 运行时、`browser`/`page` SDK、30 秒有界工作块、helper 复用。
3. **会话与标签归属**：agent/session/tab 所有权、标签组、断线重连、URL 恢复。
4. **文件链路**：上传、下载、PDF、文件类型与大小策略、恶意文件检测、外发前检测。
5. **图像链路**：截图、区域截图、视觉定位、截图脱敏与短保留期。
6. **弹窗和对话框**：alert/confirm/prompt、新窗口、权限请求、下载提示的统一事件。
7. **剪贴板完整能力**：复制、读取、写入、敏感内容检测、人工接管期间禁用。
8. **浏览器恢复**：崩溃重连、页面 generation、持久化动作账本、幂等键与重复副作用防护。
9. **Profile 隔离**：按任务/账号隔离，明确持久登录态边界，不复制个人默认 profile。
10. **配置与打包**：签名配置、模型锁定、SBOM、升级/回滚、Windows 安装包。

## 4. 可插拔模型与能力

### 感知类

- OCR、图标/目标检测、滑块缺口定位、页面视觉理解。
- DOM/AX 语义提取、元素重定位、页面状态差异。
- 表格与结构化内容提取、页面语言与区域识别。

### 动作类

- 可自定义鼠标轨迹模型、键盘输入模型、滚动与触摸模型。
- 拖拽路径、文件选择、剪贴板复制/粘贴、富文本与组合输入法。
- 动作结果校验、遮盖处理、失败后重新定位。

### 挑战与恢复类

- `ddddocr` 文字图片识别。
- 滑块、点选、旋转等专用适配器；未注册类型直接转 AI。
- AI 挑战恢复器、业务结果验证器、断点恢复策略。
- 限流、账号锁定、异常流量信号识别，命中后停止自动尝试。

### 安全类

- 间接提示词注入检测、隐藏文本/离屏元素检测、图片文字注入检测。
- 敏感信息与凭据识别、下载检测、上传外发策略、远程模型出网审计。
- 扩展与模型供应链检查、依赖哈希、资源预算、恶意图片隔离。

### 溯源与评估类

- 快照、事件、能力版本、配置哈希、输入输出摘要。
- 动作回放、失败聚类、模型准确率、AI 接管率、人工接管率、平均恢复时长。
- 基准语料、留出集、阈值校准、模型升级回归。

## 5. 安全与隐私

- 网页 DOM、AX、截图、OCR 文本、下载文件均为不可信输入，不进入控制指令槽。
- 模型只返回结构化能力结果；策略层决定是否执行，不直接授予浏览器高权限。
- 默认本地处理；远程能力必须声明 dataEgress=remote 并经过独立策略。
- 默认隔离鼠标、键盘和剪贴板状态；系统全局剪贴板仅在用户显式选择后启用。
- 审计默认不保存完整截图、密码、OTP、Cookie、填写值和 OCR 答案。
- 人工接管期间禁止自动截图、读取和动作；恢复后重新验证 origin、页面和业务前置条件。
- 非幂等动作不得因挑战恢复自动重放。

## 6. 核心指标

- 语义动作成功率与误操作率。
- 挑战检测 precision/recall、OCR 成功率、错误提交率。
- AI 恢复成功率、人工接管率、平均恢复时长。
- 断点恢复重复副作用数，目标为 0。
- 审计事件与动作一一对应率，目标为 100%。
- neo 高频工作流迁移成功率与每任务模型 token 降幅。
